# 原始资料契约

所有资料均为本地合成。JSONL一行一条来源观察，row_id仅标识该观察；同业务ID可以在不同revision、批次或接收位置出现。未写revision的静态目录按文件给定值解释，不隐含线上查询。事实字段中的None为缺少来源值，不是零或否。

金额字段以minor结尾时为该币种最小单位整数；数量、位置、时间的单位以字段后缀和政策说明为准。日期为ISO日期；绝对时刻携带偏移；原始received字段决定可见性，不能仅按发生日期提前使用资料。后续业务修改以相同格式输入，不限定样本编号。

## 业务政策

### playback

alpha相邻心跳可证明观看的条件：同会话、墙钟间隔>0且<=12000ms、播放位置前进>=0且与rate*墙钟时长相差<=1000ms、两端visible。回拖事件本身不生成观看区间，下一合法前进可以生成。beta直接区间但有效时间不超过墙钟时长；后台visible=false不计有效观看。 样本wall_ms以2026-11-20T00:00:00+08:00为原点。cut的program源长度按full版本duration_ms解释；映射均为分段线性且只在明确pieces内有效。合格量按会话计，同会话重复/修订先去重，用户数是另一口径。合同期间按会话最早墙钟日确定，日汇总按其day；没有细节的来源不自行推断合同资格。

### metrics

覆盖为映射到源节目后可证明源区间的并集长度，最多节目长；有效时间为真实墙钟观看时长，倍速不按位置跨度冒充墙钟时长。完成率为源覆盖/节目长，平台声明播放数单独展示，不强行换算。

### identity

仅allowed=true的显式映射可跨平台合并用户，未允许或无映射者单列平台内，不能宣称全局精确去重总人数。screen无会话数据，不产生精确漏斗或人数。

### compare

按平台单source_position和mapping_revision计算可比合格会话量。高于平台已确认覆盖的位置不能声称完整，source_position之外的新数据不能直接与旧单比较。event_id最高可见revision替代原观察；结算修订需引用原单。日汇总只可对平台声明量，不伪造会话资格。

## 资料检查

`python -m unittest discover -s tests -v`只检查资料字节与格式，不是尚未开发业务功能的验收。manifest.json中的摘要对应提交内原始字节，收到后续批次应独立登记来历，不修改旧原始记录。
